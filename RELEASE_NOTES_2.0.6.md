# HardwareScope 2.0.6

This update makes HardwareScope easier to set up, move between computers, and use with different visual needs.

- Adds portable `.ini` settings export and import from the General settings tab.
- Validates imported files before they can replace the current configuration.
- Adds an accessible native first-run setup with recommended and customizable paths.
- Adds standard, large, and extra-large interface text options.
- Adds an optional stronger-contrast palette for text, borders, and selections.
- Adds `Ctrl+F` for sensor search, `Ctrl+,` for Settings, and `Esc` to clear search.
- Preserves OSD sensor selections if Settings opens before the first sensor snapshot arrives.
- Keeps Stable as the single public update channel.
