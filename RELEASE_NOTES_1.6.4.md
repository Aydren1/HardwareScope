# HardwareScope 1.6.4

HardwareScope 1.6.4 makes the on-screen display more compact.

## Changes

- Removed the redundant `HARDWARESCOPE` heading from the OSD.
- The overlay now starts directly with the selected sensor readings.
- Existing OSD position, scale, opacity, color, and hardware-name settings are unchanged.

## Distribution

- Self-contained Windows x64 installer; no separate .NET installation is required.
- Includes the PawnIO sensor driver installer for supported low-level sensors.

HardwareScope 1.6.4 is currently unsigned, so Windows SmartScreen may show an unknown-publisher warning.
