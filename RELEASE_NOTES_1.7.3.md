# HardwareScope 1.7.3

## Full-width draggable headers

- Empty areas across the complete top header now receive mouse input and can move the window.
- The fix applies to both the main HardwareScope window and Settings.
- The header remains visually unchanged because its hit-test background is transparent.
- Search fields, dropdowns, toggles, buttons, and window controls remain fully interactive.
- Double-clicking a non-interactive header area still maximizes or restores the window.

## FPS monitoring

- Retains the non-blocking HWiNFO-style automatic FPS capture introduced in 1.7.2.
