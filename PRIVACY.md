# HardwareScope privacy policy

HardwareScope does not include analytics, advertising, crash reporting, user
accounts, or telemetry collection. Sensor readings, settings, and on-screen
display data remain on the local computer.

This program will not transfer any information to other networked systems
unless specifically requested by the user or the person installing or
operating it.

## Network access

When automatic update checks are enabled, or when the user selects **Check for
updates**, HardwareScope makes HTTPS requests to this project's files and
release assets on GitHub. If the user chooses to install an update, the release
installer is downloaded from GitHub and verified against its published size
and SHA-256 digest before it is started. These requests are subject to
[GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Automatic update checks can be disabled in HardwareScope settings. No hardware
sensor values, application settings, files, or personally entered information
are included in update requests.

## Local components

HardwareScope's sensor service and its packaged PresentMon component operate
locally. PresentMon is started only while game-only FPS monitoring is needed.
HardwareScope does not use either component to transmit sensor or frame data.

## Contact

Privacy questions and reports can be submitted through the project's
[GitHub issue tracker](https://github.com/Cero-SC/HardwareScope/issues).
