# HardwareScope 2.0.11

- Added a lightweight, non-activating tray quick panel for favorite and essential live sensors.
- A single tray-icon click toggles Quick View, while double-click still opens the full HardwareScope window.
- Replaced the Windows update/reminder dialog with a HardwareScope-themed in-app update window.
- Kept Update now, 24-hour, 3-day, 1-week, and skip-version choices in the new interface.
- Replaced update status and verification error message boxes with matching in-app notices.
