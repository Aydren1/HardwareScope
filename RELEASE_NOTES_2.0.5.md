# HardwareScope 2.0.5

This update simplifies HardwareScope's sensor interface around Favorites.

- Replaces the EZ Temp controls with a clear Favorites view.
- Automatically favorites the primary CPU, GPU core, and GPU memory-junction temperatures when available.
- Adds one-click stars beside every sensor so the Favorites list is easy to customize.
- Keeps existing hardware sections in Favorites, making a short list easy to scan.
- Keeps Favorites and on-screen-display selection independent.
- Simplifies the Monitoring settings page and gives the OSD sensor list more room.
- Preserves existing EZ Temp choices when upgrading.
